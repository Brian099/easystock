# 📦 EasyStock - 智能轻量库存管理系统

一款极简、现代化、全响应式的单页库存与进销存管理系统。采用 **原生 SPA 前端架构 + 轻量 PHP 后端 + MySQL 数据库**，完全本地化离线运行，零外部 CDN 依赖，支持移动端自适应。

---

## ✨ 核心特性

- 📱 **全端响应式设计**：完美适配 PC 宽屏、平板与手机移动端（内置底部导航 Dock 与手势抽屉）。
- 🏷️ **智能条形码管理**：
  - 新增商品自动生成唯一的标准 13 位 **EAN-13** 商品条形码；
  - 支持摄像头扫码录入、快速查验与历史商品条形码一键批量补全。
- 📊 **商品批量导入与导出**：
  - **导出**：一键导出当前筛选/全量商品数据为 CSV 表格（内置 UTF-8 BOM，Excel 双击打开不乱码，条码防科学计数法）；
  - **导入**：支持标准 CSV 模板导入，多编码（UTF-8/GBK）自动检测，支持冲突覆盖/跳过与缺失条码自动生成。
- 🖼️ **商品图片与画廊**：
  - 支持每件商品上传多张细节图片；
  - 展开商品详情采用 **「上方大图 + 下方缩略图索引」** 联动交互，支持点击大图全屏放大灯箱预览。
- ⚡ **智能动态下拉候选项**：
  - 商品单位、厂商/品牌和仓位从商品库实时 `SELECT DISTINCT` 提取；
  - 支持右侧小箭头展开全量预设、即时模糊搜索过滤与自由手动输入。
- 📜 **完整出入库流转审计**：
  - 记录入库、出库、退货等全生命周期库存流转日志；
  - 支持商品详情内独立关联历史流水查看。
- 🛠️ **自包含纯净安装向导**：
  - 打开浏览器即可体验可视化安装引导，无需手动导入 SQL 文件，自动完成建库、建表、优化索引与初始化管理员账号。
- 🔒 **多角色权限控制**：系统管理员（Admin）与操作员（User）分级权限。
- 🌐 **100% 静态资源本地化**：内置 FontAwesome 6 图标库与系统平滑字体栈，支持完全离线/局域网内网隔离运行。

---

## 🛠️ 技术栈

- **前端**：原生 HTML5 / CSS3 (Glassmorphism 毛玻璃拟态风格) / Vanilla JavaScript (SPA 单页应用架构)
- **后端**：PHP 7.4+ (原生轻量 RESTful API / PDO MySQL 预处理防注入)
- **数据库**：MySQL 5.7+ / MariaDB 10.3+
- **容器化**：支持 Docker & Docker Compose 一键启动

---

## 🚀 快速部署与安装

### 方式一：传统 LAMP / WAMP / 宝塔面板部署

1. **环境要求**：PHP 7.4 或更高版本，MySQL 5.7+，开启 `pdo_mysql` 和 `mbstring` 扩展；
2. **下载代码**：将本项目所有代码放入 Web 服务器根目录（如 Apache `www` 或 Nginx `html`）；
3. **访问系统**：在浏览器中直接访问您的站点地址（如 `http://localhost/` 或 `http://服务器IP/`）；
4. **安装向导**：网页将自动弹出 **「新系统安装引导」**，填写 MySQL 连接信息与管理员密码，点击 **「开始安装并初始化」** 即可一键建库完成！

---

### 方式二：Docker 一键部署

```bash
# 启动容器服务
docker-compose up -d

# 访问系统
http://localhost:8080
```

## 📂 项目结构

```text
easystock/
├── api/                    # 后端 RESTful API 接口
│   ├── auth.php            # 用户登录、登出、状态检测
│   ├── config.php          # 全局配置与 PDO 数据库单例
│   ├── export_products.php # 商品数据导出 CSV
│   ├── fill_barcodes.php   # 历史商品条码批量补全
│   ├── import_products.php # 商品批量导入与模板下载
│   ├── install.php         # 纯净自包含安装初始化引擎
│   ├── products.php        # 商品 CRUD 与图片上传管理
│   ├── settings.php        # 系统业务规则与下拉建议提取
│   ├── stock.php           # 出入库事务与流水审计日志
│   └── users.php           # 用户账号管理与权限分配
├── assets/                 # 前端静态资源
│   ├── css/
│   │   └── style.css       # 全局样式（自适应、毛玻璃、深色调微动效）
│   ├── js/
│   │   └── app.js          # 原生 SPA 前端核心应用控制器
│   └── vendor/
│       └── fontawesome/    # 本地化 FontAwesome 图标库 (CSS + Webfonts)
├── uploads/                # 商品图片上传存储目录
├── index.html              # 单页应用（SPA）主入口
├── Dockerfile              # Docker 镜像构建文件
├── docker-compose.yml      # Docker Compose 服务编排
└── README.md               # 项目说明文档
```
